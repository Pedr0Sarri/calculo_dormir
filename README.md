# Ciclo do Sono

App web (PWA) que calcula os melhores horários para dormir e acordar com base em ciclos de sono de ~90 minutos, considerando o tempo para adormecer (padrão: 15 min).

- **Quero acordar às:** informe o horário e veja quando deitar (3 a 6 ciclos).
- **Vou dormir agora:** veja em que horários programar o despertador.

Funciona offline e pode ser instalado no celular ("Adicionar à Tela de Início").

**Acesse:** https://pedr0sarri.github.io/ciclo-sono/
